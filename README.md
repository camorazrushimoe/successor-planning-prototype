# Successor Planning Prototype

Прототип системы succession planning для юнита большой аутсорс-компании (~150–200 инженеров).

Репозиторий: спецификация интерфейсов + seed-данные (`data/unit.json`) для живого прототипа.

## Зачем

Unit Head («биг босс») держит 8 партнёрских / lead-ролей. Нужно видеть:

- кто занимает роль сейчас;
- кто planned successor, кто recommended;
- готовность: ready now / 6 мес / 12 мес / 18+;
- идёт ли человек по плану развития;
- где дыра (нет ready-now, один кандидат, просроченные цели).

HRBP калибрует 9-box и не даёт зафиксировать «любимчика» без данных.

## Данные

`data/unit.json` — 150 синтетических людей + 8 критических ролей со slates.

Поля по человеку: трек, тайтл, навыки, клиентские проекты, фидбек клиента, толки с руководителем, performance × potential.

Это выдуманные люди для демо. Не прод-HR-данные.
