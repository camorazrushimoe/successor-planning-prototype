## Цели на карточке человека

Строка: текст · due · статус.

Кнопки в этой же строке:

- **удалить** — только Head
- **выполнено** если статус `open` → ставит `done`
- **не выполнено** если статус `done` → ставит `open`

Кнопки статуса есть у Head и у Candidate. Нельзя оставлять только «удалить».

## Пул / комменты / Candidate

Без изменения: пул из `people.json`; лента комментов на карточке; Candidate без чужого slate и без ленты Head/HR.
