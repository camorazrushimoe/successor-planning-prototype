## Темы пользовательских ролей

Переключатель в шапке меняет CSS-тему всей подложки.

| Роль | Фон / акцент | Что видно |
|---|---|---|
| Unit Head | тёмный + **зелёный** | slate, цели, ready_now, редакт роли |
| HRBP | тёмный + **фиолетовый** | пикер 9-box, коммент профиля |
| Observer | тёмный + **серый** | только текст и счётчики |

Правило: нет прав — кнопки **нет на экране**, не disabled. Что видно — нажимается. Акцент кнопок = цвет темы.

## Горизонт и таймлайн

На паре человек×роль: `none | ready_now | 6m | 12m | 18m`. Ready now — тоггл Head.

**Покрытие / красный счётчик** считают **только planned**.  
Recommended с горизонтом — тонкий чип на таймлайне, не закрывает дыру.

## Экран 0–1. Роль и Pipeline

Create + edit одна модалка. Смена incumbent не трогает slate, старый не становится planned.

У Head на карточке: −, + из пула, горизонт, редактировать. У HR/Обсервера этих кнопок нет.

## Экран 2A. 9-box

Сверху страницы — блок для HR, текст всегда виден:

> 9-box — не оценка «хороший/плохой». Оси: **performance →** (как работает сейчас) и **potential ↑** (потянет ли роль выше).  
> **Звезда / алмаз** — имеют смысл в planned. **Эксперт** — сильный IC, не partner «из уважения»; может быть emergency.  
> Клетка ≠ готовность к дате. Горизонт ставит Unit Head.  
> HR: клик по человеку → панель из 9 клеток + обязательный коммент → Сохранить. Не prompt.

```
potential ↑
high     | загадка (puzzle) | алмаз (diamond) | звезда (star)
medium   | слабый (weak)    | ядро (core)      | сильный IC (ic)
low      | на выход (out)   | стабильный (steady)| эксперт (expert)
         low                    medium               high  → performance
```

Панель HR: radio/checkbox на эти 9 имён (не свободный текст). Одна клетка. Без коммента Save неактивен.

Head и Observer клик открывают карточку человека, не пикер.

## Экран 3. Карточка

Цели — только для **текущей критической роли**. Другая роль — другой список. Head: add / delete / статус.

Коммент профиля — на человеке (общий), автор удаляет свой.
