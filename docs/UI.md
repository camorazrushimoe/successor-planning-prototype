# Интерфейсы · spec 0.8

См. [SPEC.md](SPEC.md).

## Пул людей

Модалка «+ из пула» и селект incumbent — полный список из локального `people.json` (поиск по имени / title / id / level / track). Не шесть зашитых имён.

## Комментарии

На карточке человека (дровер Head/HR):

1. Список уже сохранённых комментариев: автор, время, текст.
2. Textarea + кнопка «добавить».
3. После клика запись в списке, поле пустое.

Candidate этот блок не видит.

## Цели

Текст, due, статус, автор. Scope = человек × роль.

## Candidate

Только свои роли из текущего пула JSON. Нет slate коллег и нет комментов Head/HR.
